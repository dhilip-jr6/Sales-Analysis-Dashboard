# Sales-Analysis-Dashboard
An interactive Excel dashboard built to analyze sales performance across products, regions, and salespersons. The project includes data cleaning, transformation, and visualization using Pivot Tables, Charts, and Slicers to uncover key business insights and support data-driven decision-making.

📊 Sales Analysis Dashboard (Excel)
📌 Project Overview

This project focuses on analyzing sales data and presenting key business insights through an interactive Excel dashboard. The dashboard helps stakeholders understand sales performance across products, regions, and salespersons, enabling data-driven decision-making.

🎯 Objectives

Analyze overall sales performance

Identify top-performing products and regions

Track salesperson-wise sales trends

Provide an easy-to-use, interactive reporting solution

🛠 Tools & Technologies

Microsoft Excel

Pivot Tables

Charts & Graphs

Slicers

Excel formulas for data cleaning and analysis

📂 Dataset Description

The dataset contains sales transaction data including:

Product details

Region-wise sales

Salesperson information

Sales amount and quantity

Data was cleaned and structured to ensure accurate analysis.

📈 Dashboard Features

Interactive filters using Slicers

Product-wise, region-wise, and salesperson-wise analysis

Visual representation using charts and pivot tables

Summary KPIs for quick insights

🔍 Key Insights

Identified top-selling products and high-performing regions

Highlighted sales trends and performance gaps

Enabled quick comparison across different business dimensions

🚀 How to Use

Download the Excel file from the repository

Open it in Microsoft Excel

Use slicers to filter data by product, region, or salesperson

Analyze insights from the dashboard visuals

📌 Use Cases

Sales performance review

Business decision support

Practice project for data analysis and reporting

Portfolio project for Data Analyst roles
